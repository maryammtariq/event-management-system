# Submission checklist

## Finished in the source project

- [x] React with reusable components and a responsive design
- [x] Redux Toolkit store, slices, actions, reducers, selectors and dispatches
- [x] Registration, login and logout with persistent simulated authentication
- [x] Ticketmaster search, filters, categories and event details integration
- [x] User-specific registration, duplicate prevention and cancellation
- [x] Protected My Events page with upcoming and completed views
- [x] Loading, error, empty, missing-key and validation feedback
- [x] Source code, lockfile, README, environment template and .gitignore
- [x] Multiple meaningful development commits
- [x] Automated unit tests and browser test suite

## Before handing it in

- [ ] Get your own Consumer Key from the Ticketmaster Developer Portal.
- [ ] Add it only to local `.env`, restart Vite and verify real event results.
- [ ] Try one real event registration and cancellation using a demo account.
- [ ] Upload the repository with its complete Git history to your GitHub account.
- [ ] Ensure the instructor can access the repository.
- [ ] Review the code so you can explain the Redux state, routes and API calls.
- [ ] Submit only the GitHub repository URL.

Do not submit an API key or your `.env` file. A ZIP is a backup of the project, not the repository URL requested by the assignment.
